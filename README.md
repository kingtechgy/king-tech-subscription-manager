# King Tech Subscription Manager

A responsive subscription management web app for King Tech.

## Features

- 238 imported subscription records
- Customer subscriptions
- Automatic 4-digit bill numbers
- Payment tracking
- Reminder queue
- WhatsApp reminder links
- Business expenses
- Reports
- Offline-capable Progressive Web App
- Installable on Android from the live website

## Publish with GitHub Pages

1. Upload all files in this folder to the root of the repository.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select:
   - **Source:** Deploy from a branch
   - **Branch:** main
   - **Folder:** /(root)
5. Click **Save**.

The website will then be available at:

`https://kingtechgy.github.io/king-tech-subscription-manager/`

After it is live, open it in Chrome on Android and choose **Install app** or **Add to Home screen**.
