KING TECH SUBSCRIPTION MANAGER — FIREBASE 3.0

This version replaces Google Sheets and Apps Script syncing with Firebase Authentication and Cloud Firestore.

Included:
- Secure administrator sign-in
- Automatic real-time multi-device updates
- Persistent offline cache
- Per-record Firestore storage for customers, accounts, payments, expenses, and reminder history
- One-time verified JSON backup import
- Automatic date/status recalculation on every device
- No migration URL or Join Database button

Firebase setup:
1. Enable Email/Password Authentication.
2. Create approved users in Firebase Authentication.
3. Publish the contents of firestore.rules in Firestore > Rules.
4. Deploy this website update.
5. Sign in and import the verified 240-customer backup once.
6. Sign in on other devices; records download automatically.
